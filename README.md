# Dormal Makeup · Dorotea Malenić

Web stranica za profesionalnu šminku — **https://kriscro99.github.io/dormal-makeup/**

## Kontakt podaci

Na vrhu `js/main.js` nalazi se `CONFIG`. Upiši WhatsApp broj, telefon ili e-mail i
gumbi/kanali će se automatski pojaviti na stranici i u prozoru za slanje upita:

```js
const CONFIG = {
  instagram: 'dormal_makeup',
  whatsapp: '385911234567', // bez + i razmaka
  phone: '+385 91 123 4567',
  email: 'info@primjer.hr',
};
```

Slike se nalaze u mapi `img/` (`look-1.jpg` … `look-4.jpg`, uz manje `-sm` verzije za mobitele).
